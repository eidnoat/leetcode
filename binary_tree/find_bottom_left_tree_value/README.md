# [找树左下角的值](https://leetcode.cn/problems/find-bottom-left-tree-value/description/)

给定一个二叉树的 根节点 root。

请找出该二叉树的 最底层 最左边 节点的值。

 

示例 1:



输入：root = [2,1,3]
输出：1
解释：最后一行是 [1, 3]，因此最左边的值是 1。
示例 2:



输入：[1,2,3,4,null,5,6,null,null,7]
输出：7
解释：最后一层只有节点 7。
 

提示:

二叉树的节点个数的范围是 [1, 104]
-231 <= Node.val <= 231 - 1
